# Инструкция по экспорту иконок из Figma

## Способ 1: Автоматический экспорт через API (рекомендуется)

### Шаги:

1. **Получите токен доступа Figma:**
   - Перейдите на https://www.figma.com/developers/api#access-tokens
   - Войдите в свой аккаунт
   - Создайте новый токен доступа
   - Скопируйте токен

2. **Установите переменную окружения:**
   
   **Windows (PowerShell):**
   ```powershell
   $env:FIGMA_ACCESS_TOKEN="your_token_here"
   ```
   
   **Windows (CMD):**
   ```cmd
   set FIGMA_ACCESS_TOKEN=your_token_here
   ```
   
   **Mac/Linux:**
   ```bash
   export FIGMA_ACCESS_TOKEN=your_token_here
   ```

3. **Запустите скрипт:**
   ```bash
   node export-figma-icons.js
   ```

4. **Иконки будут сохранены в папку `assets/svg/`**

---

## Способ 2: Ручной экспорт (если API не работает)

### Шаги:

1. **Откройте Figma:**
   - Перейдите по ссылке: https://www.figma.com/design/6YEqoZmGzPM9sevyXOIt9G/Inspire?node-id=88-60
   - Войдите в свой аккаунт

2. **Найдите все иконки:**
   - На странице "ui kit" (node-id=88-60) найдите все иконки
   - Иконки обычно находятся в компонентах: Logo, Button icons, и т.д.

3. **Экспортируйте иконки:**
   - Выберите иконку (или несколько, удерживая Shift)
   - Правый клик > **Export** > выберите формат **SVG**
   - Или используйте панель справа: раздел **Export** > нажмите **+** > выберите **SVG**

4. **Сохраните файлы:**
   - Сохраните все SVG файлы в папку `assets/svg/`
   - Используйте понятные имена файлов (например: `logo.svg`, `search-icon.svg`, `back-arrow.svg`)

---

## Список иконок, которые нужно экспортировать:

На основе дизайна, следующие иконки должны быть экспортированы:

1. **Logo** - логотип приложения (темный квадрат с белой фигурой)
2. **Search icon** - иконка поиска (лупа в header)
3. **Back arrow** - стрелка назад (в кнопке Back)
4. **Globe icon** - иконка глобуса (в кнопке Visit)
5. **Plus icon** - иконка плюса (если есть)
6. **Other icons** - любые другие иконки, используемые в интерфейсе

---

## Проверка экспорта:

После экспорта проверьте, что все файлы находятся в папке `assets/svg/`:
```bash
ls assets/svg/
```

Все файлы должны иметь расширение `.svg` и быть валидными SVG файлами.
